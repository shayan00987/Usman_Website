USMAN KHAN WEBSITE — QUICK START

Files:
- index.html       Website structure and content
- styles.css       Responsive layout, colors, typography and visual styling
- script.js        Mobile navigation and active navigation indicator
- assets/usman-transparent.png   Transparent portrait cutout for hero and YouTube banner
- assets/usman-office.png        Office-style portrait for About section

HOW TO PREVIEW:
1. Extract the ZIP.
2. Keep the assets folder beside index.html.
3. Open index.html in Chrome. Internet is needed for Google Fonts; the site itself is plain HTML/CSS/JS.
4. For GitHub Pages, upload index.html, styles.css, script.js and the entire assets folder to the repository root.

EDITING:
- Change website text and links in index.html.
- Change colors, typography, spacing and mobile layout in styles.css.
- Change navigation behavior in script.js.

NOTE:
